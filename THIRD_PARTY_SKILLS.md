## Local curation and edits

- **Chinese UI labels:** added or localized `agents/openai.yaml` → `interface.display_name` for all five third-party skills. Skill identifiers and entrypoint instructions are unchanged by this UI update.

- **Superpowers:** retained the two selected skill entrypoints and linked runtime references/scripts. Removed `CREATION-LOG.md` and bundled pressure-test prompt files (`test-academic.md`, `test-pressure-*.md`) because they are authoring/evaluation fixtures, not runtime guidance. Upstream has an [issue discussing those bundled fixtures](https://github.com/obra/superpowers/issues/2277). Removed the unrelated defense-in-depth reference from the debugging guide to avoid recommending blanket validation. Adapted the debugging entrypoint to avoid a hard dependency on the separately named TDD skill; test creation is proportional to the task. Relaxed the fixed three-failure escalation rule. The verification guide now distinguishes a check that ran from one that did not, without requiring a full test suite for every task.
- **K-Dense:** retained complete selected skill folders (references, helper scripts, and visualization assets). Converted nonstandard `compatibility` frontmatter into descriptive metadata for loader compatibility; normalized the statistical-analysis license label. Replaced references to unbundled statsmodels/PyMC skills with official-documentation guidance. Python/package constraints are kept in the skill metadata; dependencies are not installed.
- **Karpathy guidelines:** retained its single skill entrypoint as published. It is described as inspired by Andrej Karpathy's observations, not authored by him. Its source skill states MIT, and the source README also states MIT; no separate upstream license text was present in this pinned snapshot.

Upstream wording/resources are preserved except for the adaptations listed above. Re-review upstream changes before updating pins.
